# BUG-027 — Checkbox "Lembrar-me" não tem funcionalidade implementada

**Severidade:** Baixa
**Prioridade:** Baixa
**Categoria:** UX

## Passos para Reproduzir
1. Acessar a aplicação em `http://localhost:3000`
2. Marcar o checkbox "Lembrar-me"
3. Realizar login com credenciais válidas
4. Fechar o navegador e abrí-lo novamente
5. Acessar `http://localhost:3000`

## Resultado Esperado
Usuário deve permanecer autenticado, sem precisar logar novamente.

## Resultado Atual
Usuário é redirecionado para a tela de login normalmente. O checkbox não persiste a sessão nem executa nenhuma ação.

## Evidência
Inspecionando o código fonte, o checkbox existe no HTML mas não possui nenhum handler ou lógica associada:
```html
<!-- BUG 27: Checkbox "Lembrar-me" não faz nada -->
<input type="checkbox" id="rememberMe">
<label for="rememberMe">Lembrar-me</label>
```

## Sugestão de Correção
Implementar persistência de sessão ao marcar o checkbox, utilizando `localStorage` ou cookie com expiração longa. Quando desmarcado, usar `sessionStorage` para sessão apenas enquanto o browser estiver aberto.
