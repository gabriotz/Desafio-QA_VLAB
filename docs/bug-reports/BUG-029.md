# BUG-029 — Username accepts spaces without validation

**Severidade:** Alta  
**Categoria:** Lógica / Segurança

## Passos para Reproduzir
1. Acessar a aplicação em `http://localhost:3000`
2. Clicar na aba "Registrar"
3. Preencher o campo Username com `"gab riel"` (com espaço)
4. Preencher Email, Senha e Confirmação com valores válidos
5. Clicar em "Registrar"

## Resultado Esperado
Sistema deve exibir mensagem de erro informando que o username não pode conter espaços.

## Resultado Atual
Sistema registra o usuário normalmente, sem exibir nenhuma mensagem de erro. O campo `#registerMessage` permanece com `display: none`.

## Evidência
Teste automatizado `register.cy.ts` — cenário BUG-029:
```
AssertionError: Timed out retrying after 8000ms: expected '<div#registerMessage.message.error>' to be 'visible'
This element is not visible because it has CSS property: display: none
```
Screenshot gerado automaticamente pelo Cypress na execução.

## Impacto
Usernames com espaços podem causar problemas em:
- URLs que usam o username como parâmetro
- Sistemas que usam o username como identificador único
- Integrações que não esperam espaços em identificadores

## Sugestão de Correção
Adicionar validação no frontend antes do submit:
```js
if (/\s/.test(username)) {
  showMessage('Username não pode conter espaços', 'error')
  return
}
```
E reforçar também no backend com uma regex de validação.
