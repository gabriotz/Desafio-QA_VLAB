# BUG-030 — Email field has type="text" instead of type="email"

**Severidade:** Média  
**Categoria:** UX / HTML Semântico

## Passos para Reproduzir
1. Acessar a aplicação em `http://localhost:3000`
2. Clicar na aba "Registrar"
3. Inspecionar o campo de email via DevTools (F12)

## Resultado Esperado
```html
<input type="email" id="registerEmail" data-testid="register-email">
```

## Resultado Atual
```html
<input type="text" id="registerEmail" data-testid="register-email">
```

## Evidência
Teste automatizado `register.cy.ts` — cenário BUG-030:
```
Timed out retrying after 8000ms
+ expected - actual

-'text'
+'email'
```
Confirmado também via inspeção do HTML — comentário no código fonte indica que o bug é conhecido:
```html
<!-- BUG-030: tipo deveria ser "email" -->
```

## Impacto
- Navegador não aplica validação nativa de formato de email antes do submit
- Em dispositivos móveis, o teclado não é otimizado para entrada de email (sem `@` em destaque)
- Viola boas práticas de HTML semântico

## Sugestão de Correção
Alterar o atributo `type` do campo:
```html
<!-- De -->
<input type="text" id="registerEmail" ...>

<!-- Para -->
<input type="email" id="registerEmail" ...>
```
