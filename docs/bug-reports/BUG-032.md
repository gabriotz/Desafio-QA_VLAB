# BUG-032 — Password confirmation validated only on backend, not on frontend

**Severidade:** Baixa / UX  
**Categoria:** UX / Lógica

## Passos para Reproduzir
1. Acessar a aplicação em `http://localhost:3000`
2. Clicar na aba "Registrar"
3. Preencher Username e Email com valores válidos
4. Preencher Senha com `"Password123"`
5. Preencher Confirmação de Senha com `"Different456"`
6. Clicar em "Registrar"

## Resultado Esperado
Sistema deve detectar que as senhas não coincidem **antes** de enviar ao backend, exibindo erro imediatamente no frontend.

## Resultado Atual
Sistema envia os dados ao backend, que retorna o erro. A validação só acontece após a requisição, adicionando latência desnecessária e round-trip ao servidor para um erro que poderia ser capturado localmente.

## Evidência
Teste automatizado `register.cy.ts` — cenário BUG-032:
```
✓ should show error when passwords are different [BUG-032: validation is backend-only]
```
O teste passa porque o erro aparece (via backend), mas o comportamento esperado seria que o erro ocorresse **antes** do request ser feito.

## Impacto
- UX degradada: usuário aguarda resposta do servidor para um erro evitável
- Round-trip desnecessário ao backend
- Em conexões lentas, a experiência é visivelmente pior

## Sugestão de Correção
Adicionar validação no frontend antes do submit:
```js
if (password !== confirmPassword) {
  showMessage('As senhas não coincidem', 'error')
  return
}
```
