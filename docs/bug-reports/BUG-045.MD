BUG-045 — Taxa de Conclusão aceita valores negativos
Severidade: Alta
Prioridade: Alta
Categoria: Lógica / Validação
Passos para Reproduzir

Logar na aplicação com credenciais válidas
Navegar para /coleta
Preencher o campo "Taxa de Conclusão (%)" com -50
Preencher demais campos com valores válidos
Clicar em "Submeter Coleta"

Resultado Esperado
Sistema deve exibir mensagem de erro informando que o valor não pode ser negativo.
Resultado Atual
Sistema aceita o valor e registra a coleta normalmente com taxa de -50%.
Evidência
Teste automatizado coleta.cy.ts — cenário BUG-045:
AssertionError: expected '<div#coletaMessage.message.success>' to be 'visible'
A mensagem retornada foi de sucesso, não de erro — confirmando que o sistema não validou o valor negativo.
Sugestão de Correção
Adicionar validação no frontend e backend:
jsif (taxaConclusao < 0) {
  showMessage('Taxa de Conclusão não pode ser negativa', 'error')
  return
}
