BUG-047 — Nota de Avaliação não possui limite máximo de 10
Severidade: Alta
Prioridade: Alta
Categoria: Lógica / Validação
Passos para Reproduzir

Logar na aplicação com credenciais válidas
Navegar para /coleta
Preencher o campo "Nota de Avaliação (0-10)" com 99
Preencher demais campos com valores válidos
Clicar em "Submeter Coleta"

Resultado Esperado
Sistema deve exibir mensagem de erro informando que a nota deve estar entre 0 e 10.
Resultado Atual
Sistema aceita o valor e registra a coleta com nota 99.
Evidência
Teste automatizado coleta.cy.ts — cenário BUG-047:
AssertionError: expected '<div#coletaMessage.message.success>' to be 'visible'
A mensagem retornada foi de sucesso, confirmando ausência de validação do limite máximo.
Sugestão de Correção
jsif (nota < 0 || nota > 10) {
  showMessage('Nota deve estar entre 0 e 10', 'error')
  return
}
