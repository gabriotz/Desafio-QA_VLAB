BUG-052 — Histórico de coletas expõe dados de todos os usuários
Severidade: Crítica
Prioridade: Alta
Categoria: Segurança / Privacidade
Passos para Reproduzir

Logar com usuário A e submeter uma coleta
Fazer logout
Logar com usuário B
Navegar para /coleta
Clicar na aba "Histórico" e depois em "Carregar Histórico"

Resultado Esperado
Usuário B deve visualizar apenas suas próprias coletas.
Resultado Atual
Usuário B visualiza as coletas de todos os usuários do sistema, incluindo as do usuário A.
Evidência
Teste automatizado coleta.cy.ts — cenário BUG-052:
AssertionError: expected '<div#historicoData>' not to contain 'admin'
O histórico carregado continha registros de outros usuários. Confirmado também manualmente — coletas do usuário gab apareceram na sessão de outro usuário.
Impacto
Viola a privacidade dos beneficiários e dos avaliadores. Qualquer usuário autenticado pode visualizar dados sensíveis de avaliação de outros usuários.
Sugestão de Correção
Filtrar o histórico no backend pelo usuário autenticado na sessão:
js// Retornar apenas coletas do usuário logado
const coletas = await Coleta.findAll({ where: { userId: req.user.id } })
